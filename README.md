# 🛡️ WhatsHide

WhatsHide is a privacy-focused browser extension for WhatsApp Web. It gives you more control over read receipts and activity indicators while using WhatsApp Web.

## ✨ Features

- 🔵 Block blue ticks / read receipts
- 👁️ Read messages privately
- 🟢 Hide online status
- ⌨️ Hide typing indicators
- 🎙️ Hide recording indicators
- 📸 View Status privately where supported
- 🗑️ Anti-delete support where supported
- 🛡️ Integrated WhatsApp Web privacy controls
- 🎨 Custom WhatsHide branding and icons
- ⚡ Manifest V3 support for Chrome and Edge

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
3. Enable **Developer mode**.
4. Choose **Load unpacked**.
5. Select the WhatsHide extension folder.
6. Open WhatsApp Web.

## Compatibility

WhatsApp Web changes frequently. Some features may require updates when WhatsApp changes its web client.
